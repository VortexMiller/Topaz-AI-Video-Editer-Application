## 🧠 Overview

Topaz Video is a desktop video processing application developed by Topaz Labs. It applies AI models to footage to upscale resolution, reduce noise, sharpen detail, stabilise shaky shots and smooth motion.

The program is used in post-production workflows where source footage needs improvement before delivery. Operators load clips, select a model and settings, then render output files. It complements rather than replaces a nonlinear editor, and is typically used for restoration, archival work and preparing low-resolution material for higher-resolution delivery.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| ⬆️ AI upscaling | Increases video resolution using trained models that reconstruct detail. |
| 🧹 Noise reduction | Removes grain and compression artefacts from footage. |
| 🔪 Detail sharpening | Applies model-based sharpening to soften blur and recover edges. |
| 🎥 Video stabilisation | Reduces camera shake and jitter in handheld footage. |
| 🎞️ Frame interpolation | Generates intermediate frames to smooth motion or raise frame rate. |
| 🆚 Model comparison | Renders and compares results from different AI models side by side. |
| 💾 Batch rendering | Processes multiple clips in a queue with shared settings. |
| 🖥️ Desktop processing | Runs locally on the user's machine rather than in the cloud. |
